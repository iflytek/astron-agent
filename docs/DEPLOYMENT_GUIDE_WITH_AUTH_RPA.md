# External RPA integration

Astron Agent manages and executes RPA resources using the external platform’s API Key. Configure Console using the [deployment guide](DEPLOYMENT_GUIDE.md).

Deploy the RPA platform separately and use its own account to obtain an API Key. In Console, configure the RPA resource with that key and the task information from the external platform. Console sign-in and external RPA sign-in are independent; a combined launcher and unified sign-in are not provided.

For Console registration and existing-user upgrades, see [account setup and migration](DEPLOYMENT_GUIDE_WITH_AUTH.md).
