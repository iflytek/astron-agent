# 02 空间与资源管理

父需求：[Python Console 与统一 Agent](../requirements.md)。前置：01 Python 登录与原 UID 导入可用。

## 范围与验收

- 迁移用户空间、企业、成员、邀请、申请、角色权限、通知与授权管理。保留原成员关系和资源所有权；新账号能创建个人资源；跨空间访问按实际权限拒绝。
- 迁移模型管理、平台账号/凭据、工具市场与工具管理、MCP、RPA 管理、知识库/文档/文件、数据库资源管理，以及相应前端接口。保留 core/tenant、knowledge、plugin、memory/database 的能力边界。
- 迁移内部授权模型配置、Skill 沙箱凭据及文件/产物上传等由控制台提供的资源接口；鉴权失败不得降级为匿名或暴露凭据。
- 用户可在页面实际创建、编辑、检索、删除当前有权管理的资源；数据和对象存储内容不因语言迁移丢失。凭据加解密及引用关系保持可用。
- 相关 Redis/MinIO/数据库变更先核实依赖；新实现不读 Java 专有缓存格式作为运行前提。
- 删除本域已替代 Java 代码、对应测试和陈旧配置。以用户端和内部调用端验收，不能只通过空接口或模拟成功。

Agent 定义与聊天归 03，工作流业务编排归 04，发布渠道归 05；资源的权限与凭据接口归本子需求，避免重复实现。
