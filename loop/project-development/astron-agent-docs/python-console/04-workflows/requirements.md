# 04 工作流与 Agent 引用

父需求：[Python Console 与统一 Agent](../requirements.md)。前置：03 Agent 定义/版本解析、统一执行与记忆隔离可用。

## 范围与验收

- 迁移控制台工作流创建、编辑、版本、导入导出、模板、调试/单节点调试、运行、暂停/恢复、停止、历史/追踪、统计、定时自动化及产物管理。
- core/workflow 继续拥有图调度、变量、节点状态、重试与输入输出；控制台拥有权限和管理，core/agent 拥有 Agent 决策与工具循环。
- Agent 节点可选择已创建的独立 Agent，新运行解析最新已发布版本；编辑未发布草稿不影响运行。执行中的运行、重试和恢复使用本次固定的版本；下次新运行才更新。
- 已有内联 Agent 节点配置可转换为统一执行配置；不复制另一套引擎。节点历史与独立聊天隔离，长期偏好按父需求默认共享。
- 引用 Agent 的执行权限、其资源权限及凭据在运行时校验；删除、撤权或不存在的发布版本明确失败，不回退到草稿或越权身份。
- 处理 Agent 将工作流作为工具时的循环引用、调用深度、总预算及取消传播，避免跨服务无限递归和重复副作用。
- 前端画布、执行与调试在实际环境验证；旧工作流数据保留。删除本域已替代 Java 与重复代码。

资源和凭据基础属于 02，Agent 内核和版本快照属于 03，发布渠道/审批属于 05。节点不能自行管理用户身份或再实现长期记忆存储。
