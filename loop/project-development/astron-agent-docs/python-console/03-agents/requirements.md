# 03 独立 Agent 与统一执行

父需求：[Python Console 与统一 Agent](../requirements.md)。前置：02 空间权限、资源和授权凭据可用。

## 范围与验收

- 迁移提示词 Agent 创建/编辑/删除、列表/收藏、人格配置、调试会话、聊天、历史、重新回答、停止生成、文件输入和长期记忆管理。
- 独立聊天和调试通过统一执行请求调用 `core/agent`，删除 Java Spring AI 执行及重复工具编排。模型、MCP、Skill、插件、工作流工具、知识检索的配置和错误语义统一。
- 管理端拥有 Agent 定义和不可变版本快照；执行端使用已授权解析结果。为 04 提供已发布版本解析契约，为 05 提供发布切换接口。旧配置可迁入，不保留旧执行引擎。
- 前端能观察文本增量、工具结果、知识引用、结束和错误，取消后上游停止；部分响应和历史按实际结果保存，不虚报成功。
- 同一用户同一 Agent 的长期偏好在独立与工作流入口默认共享；命名空间包含空间/用户/Agent 身份，不随版本变化。历史按具体会话隔离。工作流内部中间数据不作为用户偏好自动保存。
- 保留现有 Mem0 配置与已有记忆访问；从 Java 迁移密码/凭据处理，默认继承原用户身份。跨用户、跨空间记忆读取被拒绝。
- 覆盖正常聊天、调试、重答、停止、工具失败、检索失败、服务断开和用户隔离。删除本范围旧 Java 和死代码。

工作流节点配置、引用及运行生命周期归 04；发布渠道、审批、市场上架归 05。本域提供统一执行和定义契约，不拥有工作流 DAG 调度。
