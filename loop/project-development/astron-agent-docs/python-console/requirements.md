# Python Console 与统一 Agent

## 目标与现状

将 `console/backend` 的 Java hub、toolkit、commons 全部替换为 Python 控制台，统一独立 Agent 与工作流 Agent 节点的执行逻辑，移除 Casdoor，提供内部账号系统。

迁移前，独立聊天和调试由 Java Spring AI 执行；工作流 AgentNode 经 HTTP/SSE 调用 `core/agent` 的 Deep Agents 内核。Java 同时负责配置、权限、发布、历史、长期记忆、资源管理和内部凭据接口。目标实现统一采用 Python Console 管理与 Core 执行；实际调用链以源码为准，旧 Chat/CoT 与 Memory 描述不作为实现前提。

## 已确定的共同要求

- R1：最终完整替换 Java Console，保留现有产品能力、用户 ID、用户资源归属、Agent/工作流配置及业务数据。
- R2：整个迁移在工作分支完成，中间阶段允许未迁移功能不可用。直接实现目标架构，不建设 Java/Python 双运行、旧代码适配层、灰度切换或兼容回退。前后端可同步调整；最终恢复用户使用流程。不得把允许代码不兼容理解为允许删除数据库或用户数据。
- R3：独立 Agent、调试和工作流 Agent 节点使用 `core/agent` 的同一执行内核、工具语义与事件模型。管理后台和工作流调度不并入 Agent 引擎。
- R4：工作流可以引用已创建的独立 Agent；新运行解析最新已发布版本，未发布修改不生效。同次运行、重试和恢复保持已解析的版本，后续运行可获得新版本。
- R5：独立聊天与工作流会话历史隔离；同一空间中同一用户使用同一 Agent，默认共享长期偏好，记忆不按 Agent 发布版本割裂。共享不跨用户或越过空间权限。工作流临时变量、工具原始结果不自动成为长期偏好。
- R6：删除 Casdoor，提供用户名＋密码开放注册、登录、退出、修改密码；首版不依赖邮件/短信。旧账号保留原 UID 和资源归属，经可信管理员发放一次性重设链接设置新密码，不能凭用户名自行认领旧账号。提供按原用户名执行的命令，显示实际登录名和重设链接；不迁移 Casdoor 密码，不引入过度检查或自动备份流程。
- R7：被当前子需求替代的旧实现、死代码、依赖、部署配置和测试一起清理。未迁移业务源码在其所属子需求完成时删除；最终运行、构建、部署不依赖 Java 或 Casdoor。
- R8：遵循官方框架/SDK，Context7 核验第三方 API。权限与内部服务身份保持有效，凭据不进入客户端、日志或 Agent/工作流持久配置。
- R9：迁移保留既有产品的导航、视觉规范和操作习惯。前端同步调整指接口、认证与新能力所需改动，不表示重做整体 UI；复用原有 Logo、图标、布局和组件。新增样式须限定作用范围，不得覆盖 Ant Design 控件的内部布局和状态样式。

## 子需求与依赖

| 顺序 | 子需求 | 用户可观察结果 | 依赖 |
|---|---|---|---|
| 01 | [内部账号与 Python 控制台基础](01-accounts/requirements.md) | 不使用 Casdoor 即可注册、登录和重设旧账号密码 | 无 |
| 02 | [空间与资源管理](02-resources/requirements.md) | 用户可按权限管理空间、模型、知识、工具及文件等资源 | 01 |
| 03 | [独立 Agent 与统一执行](03-agents/requirements.md) | 可创建、调试、聊天和管理记忆，统一使用 core/agent | 02 |
| 04 | [工作流与 Agent 引用](04-workflows/requirements.md) | 工作流可管理和执行，并复用已发布独立 Agent | 03 |
| 05 | [发布渠道与完整产品交付](05-publishing/requirements.md) | 发布、共享、渠道、应用等能力恢复，Java/Casdoor 完全退出 | 04 |

各子需求分别拥有其业务接口、前端配套、数据迁移、测试及文档。全局架构只在父目录维护；整体迁移收尾包含 UI 保真与 01—05 全部子需求回归，不能以部分渠道可用代表总体完成。

## 总体验收

1. 全部子需求的验收标准通过，现有用户身份与业务资源关联不丢失；新环境和已有业务数据库均可部署。
2. 前端核心用户流程、对外发布接口和内部服务调用完成最终联调，重启后配置与账号有效。
3. 两种 Agent 入口使用同一执行内核；最新版选择、会话隔离和偏好共享可通过测试观察。
4. Python Console 运行和 CI/镜像/Compose/Helm 中无 Java/Casdoor 执行依赖，已替代源码和陈旧指引已删除或改写。
5. 全量完成前不合并主分支；中间子需求部署仅用于其范围验证，不发布为全量迁移完成。
