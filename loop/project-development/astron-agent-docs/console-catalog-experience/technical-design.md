# 实现与验证

## 设计

1. 删除 BasicLayout 的路径栏与废弃依赖；桌面目录内边距纵向收至 20px，标题 22px/30px，标题及工具行间距 12–16px，页签收紧。保留准确说明文字但弱化占比。资源、模型、发布目录按同一密度调整，窄屏保持可换行与操作可见。
2. 发布 Bot 前端类型与后端序列化补齐 avatar；真实图片及类型默认图标使用统一回退。个人模型通过 URL 解析与确切官方主机表选择品牌资产，第三方端点使用用户 SVG；旧平台官方模型保留真实头像/品牌资产回退。主机名相似或协议兼容不能冒充官方。
3. 市场复用 catalog 样式，使用真实 Link 扩展点击区域，收藏星形按钮位于独立层级，保留错误、空、加载状态。工作流发布快照以 workflowCategory 冻结真实 category，市场投影和分类筛选使用该可信字段；历史快照缺少该字段时按未分类处理，不改写历史定义。
4. 工作流新增用户收藏表/迁移及幂等写入接口，列表支持收藏筛选并返回状态。分类沿用现有 BotType 目录及 Agent.bot_type/Workflow.category，补齐 Agent 定义契约，目录支持选择与显示。
5. 工作流编辑弹窗头像空值、加载失败回退默认 SVG，仍保留换图入口。后端分类与收藏操作采用现有授权路径。

## 验证

- 本地运行前端 `npm run type-check`、相关文件 ESLint/Prettier 及 `npm run build:test`；不为纯间距改动添加实现镜像测试。
- Django 测试覆盖收藏幂等、持久化、跨用户/空间边界，分类保存和筛选，以及发布头像投影。
- 独立代码审查覆盖全部未提交改动；修复后重新执行后续阶段。
- 全量代码完成后一次部署测试环境；通过真实浏览器检查 Agent、工作流、资源、模型、发布与市场的紧凑首屏、实际头像、卡片点击/独立收藏、工作流收藏刷新与筛选、分类保存展示筛选、编辑弹窗头像。检查窄屏以及长名称。
- 本次用户要求统一发布测试验收，生产发布不在本次适用范围。
