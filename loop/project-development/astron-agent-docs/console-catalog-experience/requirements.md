# 控制台目录体验统一

本需求覆盖控制台目录体验及市场分类筛选，统一部署测试；不拆为依次发布的子需求。沿用现有银白电蓝设计及双侧栏。

## 范围与验收

- R1：移除控制台工作区顶部“空间 / 应用构建、使用文档”路径栏。Agent、工作流、资源、模型与发布/市场目录使用紧凑标题及筛选区，减少首屏抬头高度，保留创建与业务操作。窄屏可换行，无横向溢出。
- R2：发布管理的对象列表显示对应 Agent、工作流真实头像；无头像或图片加载失败时使用相应默认头像。
- R3：个人模型中的官方供应商直连模型显示对应官方头像；第三方端点模型统一使用用户提供的 personal-model-card-icon.svg。个人模型存储来源不等于供应商品牌：应按解析后的确切官方端点主机识别，不能仅按 OpenAI 兼容协议或模型名称推断。
- R4：Agent 市场使用构建目录相同的卡片布局，显示头像、名称、用途、类型等真实信息。点击卡片打开已发布使用页面，收藏使用独立星形按钮，操作收藏不导航；保留键盘访问与错误反馈。
- R5：工作流提供与 Agent 一致的收藏/取消、收藏筛选。收藏按用户持久化，刷新后保留，不改变其他用户或空间权限。
- R6：Agent 与工作流目录展示分类并支持分类筛选；编辑/创建设置保存后能重新读取。未分类资源可识别，不臆造分类。
- R7：工作流编辑弹窗显示当前图标，空值/失效图片使用默认头像；仍可修改图标并保存。
- R8：Agent 市场沿用构建目录的搜索工具栏，支持名称搜索、全部分类/具体分类/未分类、全部/仅收藏及刷新。名称、分类和个人收藏条件取交集，在服务端分页前生效，总数与卡片一致；条件变化回到第一页，清除条件可恢复全部结果。仅收藏中取消收藏后该卡片及时移除并校正页码。分类取已发布快照，不混入未发布草稿；旧工作流快照缺少可信分类时按未分类处理。桌面与窄屏控件可见可操作，分类读取失败可重试。

## 约束

保留当前账号、空间授权、真实资源和发布版本。仅更改 Console 管理与前端体验，不修改 Core 执行、Kafka、Redis、MinIO 或认证流程。全部改动完成并独立审查后统一部署既有测试环境，再通过真实浏览器验收。本次发布范围为测试环境。
